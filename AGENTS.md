# RustX contributor instructions

Read [Roadmap](docs/ROADMAP.md), [Features](docs/FEATURES.md), and the [agent handoff](docs/AGENT_GUIDE.md) before changes.

Preserve mount-once component setup and Rust ownership of layout, text, editing, and the scene. Keep the current demo runnable from source. Keep standalone validation files, output, and archives out of the repository. Use the roadmap to record actual platform results and unresolved requirements. Browser, Windows, GPU, IME, and screen-reader claims require direct evidence for the relevant platform. Python is not a build or runtime dependency.
